Files included:
1. streamlit_n0_generator_app.py
2. requirements_streamlit_app.txt

How to run:
1. Put the following files in the same folder:
   - streamlit_n0_generator_app.py
   - N0_Report_Summary_Updated.xlsx
   - generator_outputs.zip
2. Open terminal in that folder.
3. Install packages:
   pip install -r requirements_streamlit_app.txt
4. Run the app:
   streamlit run streamlit_n0_generator_app.py

You can also upload the Excel and ZIP files from the app sidebar instead of keeping them in the folder.
